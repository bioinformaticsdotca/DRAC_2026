DRAC Primer Session 2026

Introduction

Welcome to the Canadian Bioinformatics Workshops (CBW) DRAC Primer Session. This hands-on course introduces a shared high-performance computing (HPC) training cluster and the commands needed to run reproducible bioinformatics analyses.

You will learn how to connect, manage files, transfer data, use software, submit and monitor Slurm jobs, and access interactive computing resources. The workshop finishes with a short bioinformatics challenge.

Workshop details

Date: Wednesday, October 28, 2026. Audience: CBW participants who are new to Linux or HPC. Platform: DRAC-hosted CBW training cluster. The instructors will provide the registration link and workshop credentials; do not post passwords in shared documents.

Before the session

  • Bring a laptop with a working internet connection and an SSH client (Terminal on macOS/Linux, or Windows Terminal/PowerShell with OpenSSH).
  • Open the link https://mokey.cbw.c3.ca, and register your username, password and email address as instructed.
  • This session targets the beginners who has little experience in command line, linux, and HPC.
  • The login host for this workshop is @cbw.c3.ca; do not use a personal DRAC cluster account unless instructed.
  • Use the workshop-specific instructions rather than assumptions about other DRAC clusters.
