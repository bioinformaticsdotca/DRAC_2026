Bioinformatics mini-challenge

Goal

Combine shell operations, a small sequence dataset, a reproducible script and a Slurm batch job. All data are generated inside your workspace; no external downloads are required.

Step 1: Create a sample FASTA file

mkdir -p ~/cbw-primer/challenge
cd ~/cbw-primer/challenge
cat > sequences.fa <<'EOF'
>seqA
ACGTACGT
>seqB
GGGTTT
>seqC
ATATATATAT
EOF

FASTA records begin with > followed by an identifier and one or more sequence lines.

Step 2: Explore the data

head sequences.fa
grep -c '^>' sequences.fa
wc -l sequences.fa

Question: How many sequences are present? Why is wc -l not always a reliable sequence counter for FASTA?

Answer

There are 3 sequences. FASTA sequences can occupy multiple lines, so counting total lines does not count records reliably. Counting header lines beginning with > is appropriate for well-formed FASTA.

Step 3: Build a simple analysis script

Save the following as analyze.sh:

#!/bin/bash
set -euo pipefail
input="${1:?Usage: bash analyze.sh INPUT.fa}"
printf 'Input: %s\n' "$input"
printf 'Sequences: '
grep -c '^>' "$input"
printf 'Total bases: '
awk '!/^>/ {gsub(/[[:space:]]/, ""); n += length($0)} END {print n+0}' "$input"

Run it:

bash analyze.sh sequences.fa

Expected results: 3 sequences and 24 bases. The base count sums sequence-line lengths and supports wrapped FASTA records.

Step 4: Submit the analysis to Slurm

Save as analyze.sbatch:

#!/bin/bash
#SBATCH --job-name=fasta-count
#SBATCH --time=00:05:00
#SBATCH --cpus-per-task=1
#SBATCH --mem=1G
#SBATCH --output=fasta-count-%j.out

set -euo pipefail
cd "$SLURM_SUBMIT_DIR"
bash analyze.sh sequences.fa

Run:

sbatch analyze.sbatch
squeue -u "$USER"

Once it finishes, inspect the fasta-count-JOBID.out file (replace JOBID with the actual number). If your training allocation requires --account or --partition, use the instructor-provided values.

Step 5: Save and transfer results

From your laptop, retrieve the output with rsync (substitute the job ID and workshop username):

rsync -avh YOUR_USERNAME@cbw.c3.ca:~/cbw-primer/challenge/fasta-count-JOBID.out ./

Stretch challenge

Modify analyze.sh to accept multiple FASTA files, using a for filename in "$@" loop. Consider how you would process hundreds of files using a Slurm job array rather than running one long serial task.

Wrap-up

You have registered and logged in to an HPC training cluster, organized data, used environment modules, submitted and inspected a job, and run a reproducible bioinformatics script. For production work, benchmark resource usage and use the official cluster documentation and policies.
