Welcome to the \textbf{Canadian Bioinformatics Workshops (CBW) DRAC Primer Session}. This hands-on course introduces a shared high-performance computing (HPC) training cluster and the commands needed to run reproducible bioinformatics analyses.

You will learn how to connect, manage files, transfer data, use software, submit and monitor Slurm jobs, and access interactive computing resources. The workshop finishes with a short bioinformatics challenge.

\section{HPC terminology}\label{hpc-terminology}

\begin{itemize}
\tightlist
\item
  \textbf{CPU core:} unit of CPU computation requested by a job.
\item
  \textbf{Memory (RAM):} memory required while a job runs.
\item
  \textbf{Wall time:} maximum elapsed run time requested.
\item
  \textbf{Job:} work the scheduler executes with an allocated resource request.
\item
  \textbf{Partition:} scheduling queue or resource grouping (available partitions vary).
\end{itemize}

\chapter{Module 4. Submit and monitor jobs with Slurm}\label{module-4.-submit-and-monitor-jobs-with-slurm}

\section{Why use a scheduler?}\label{why-use-a-scheduler}

On HPC, computation is submitted as a \textbf{job}. Slurm reserves cores, memory and time, and executes the job on an allocated compute node rather than on the login node.

\section{Write a batch script}\label{write-a-batch-script}

\CommentTok{\#SBATCH {-}{-}ntasks=1}

\begin{Shaded}

\textbf{Question:} How many sequences are present? Can I use \texttt{wc\ -l} then devided by 2 to count the number of sequences?

Answer

There are \textbf{3 sequences}. FASTA sequences can occupy multiple lines, so counting total lines does not count records reliably. Counting header lines beginning with \texttt{\textgreater{}} is appropriate for well-formed FASTA.

\section{3: Build a simple analysis script}\label{build-a-simple-analysis-script}

\section{7. Best practices}\label{best-practices}

\begin{itemize}
\tightlist
\item
  Do NOT run the entire workflow in a single job!!!!!!
\item
  Estimate the walltime, RAM, CPUs etc by benchmarking the tools
\item
  Find the bottleneck of the tool
\item
  Avoid duplicating the large public dataset such as NCBI BLAST database, Kraken2, Alphafold3, ColabFold, gnomAD ete, which might be found at: \texttt{/cvmfs/bio.data.computecanada.ca}
\item
  Understand the pros/cons of different file systems, such as \texttt{\$SLURM\_TMPDIR}, \texttt{/scratch}, \texttt{/project}, \texttt{/home}, \texttt{/nearline}
\end{itemize}
