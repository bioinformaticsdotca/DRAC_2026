Module 3. Software environments and reproducibility

Learning goals

Find available software, load an environment module, and identify the commands and versions used in an analysis.

Environment modules

Clusters provide software through environment modules. Available applications and versions depend on the training system.

module avail
module list
module spider python       # Available on systems using Lmod
module load python         # If an appropriate Python module is available
python --version
module list

module load modifies your environment (for example PATH) for the current shell. When finished, you can use module unload <module-name> or module reset.

Python virtual environments

If Python and the venv module are available:

virtualenv --no-download ~/cbw-primer/venv
source ~/cbw-primer/venv/bin/activate
python --version
which python
pip install --no-index emoji
pip list
python -c 'import emoji;print(emoji.emojize(":elephant:"))'
deactivate
python -c 'import emoji;print(emoji.emojize(":elephant:"))'

For those who would like to use Conda:

Create a definition file, e.g. alignment.def and edit as needed:

Bootstrap: docker
From: ubuntu:22.04
Stage: build

%environment
 export LC_ALL=C
 source /usr/local/miniconda3/bin/activate alignment

%post
 apt update && apt install -y wget
 mkdir /conda
 cd /conda
 wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh -O miniconda.sh
 bash miniconda.sh -b -u -p /usr/local/miniconda3
 rm miniconda.sh
 export PATH="/usr/local/miniconda3/bin":$PATH
 eval "$(/usr/local/miniconda3/bin/conda shell.bash hook)"
 conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/main
 conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/r
 conda create -y -n alignment
 conda activate alignment
 conda install -n alignment -y bioconda::bwa
 rm -rf /conda

Create the container image, which is called singularity container image file (sif):

module load apptainer
apptainer build allignment.sif allignment.def

Run the software built in the container:

module load apptainer
apptainer exec alignment.sif bwa -h

Exercise

  2. Find the installation path of loaded SPAdes.
  3. Install numpy in venv.
