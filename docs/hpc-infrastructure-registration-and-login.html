DRAC Primer Session 2026

HPC infrastructure, registration and login

Learning goals

By the end of this module, you should be able to describe a training cluster, register for the workshop, and connect through SSH.

What is HPC?

A high-performance computing (HPC) cluster combines many networked computers. A login node is the entry point for editing files and submitting work; compute nodes execute jobs. A scheduler (Slurm in this workshop) assigns compute resources according to job requirements and policy. Shared storage lets compute nodes access project data.

Component Purpose
Login node SSH access, lightweight editing, compilation, job submission
Compute node CPU and memory resources for running analyses
Slurm Queues, allocates and monitors jobs
Shared storage Stores data accessible to jobs

Important: Do not run computationally intensive analyses on login nodes. Submit batch jobs or request interactive allocations.

Register for the workshop

  1. Open the registration link provided by the instructors (the address is not included here because it has not yet been confirmed).
  2. Register the required username, password and email.
  3. Keep your credentials private. Use the workshop account, which may be distinct from a regular DRAC account.

Connect by SSH

Open Terminal (macOS/Linux) or Windows Terminal / PowerShell with OpenSSH:

ssh YOUR_USERNAME@cbw.c3.ca

Replace YOUR_USERNAME with the username you registered. Confirm the host key only after verifying the hostname with the instructors, then enter your password when prompted. The password is not shown as you type.

Verify where you are:

whoami
hostname
pwd

Log out:

exit

Exercise: first login

  1. Connect to cbw.c3.ca.
  2. Run whoami, hostname, and pwd.
  3. Identify which machine you are on and why intensive computation belongs on compute nodes.
Check your understanding

whoami prints your login name; hostname prints the machine name; pwd prints your current directory. Exact values depend on your account and the current training infrastructure.

Common connection issues

  • Permission denied: Confirm the username and workshop password; do not share credentials.
  • Could not resolve hostname: Check that cbw.c3.ca was entered correctly and that your network can resolve it.
  • Connection timed out: Check connectivity or ask the instructor whether network access is restricted.
